My two tools

Claude

  • Heavy lifting on coding
  • More connectors
  • Familiar chat, like ChatGPT
  • Claude in Chrome navigates sites for you

Grok

  • Most functional day to day
  • Set up like a team of employees
  • Own browser: log in with your credentials, no API keys
  • Talk to it by voice
Grok example: I trained it to put documents into my transaction system (Sisu), so I don't have to.

What I dropped
  • Building too big, too fast
  • Everything connected to everything
  • Piles of scheduled automations that broke and burned money
  • Managing a thousand data points instead of producing
Lesson: stay organized as an agent. Maximize output on the tasks you dislike.
